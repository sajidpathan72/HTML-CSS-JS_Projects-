# HTML-CSS-JS_Projects-

A collection of small, self-contained web projects built with vanilla **HTML**, **CSS**, and **JavaScript**.

No frameworks, no build step — clone the repo and open any `index.html` in your browser.

## Projects

| # | Project | Folder | What it does |
| --- | --- | --- | --- |
| 1 | Document | `project1/` | Basic HTML document / starter layout |
| 2 | Search Github Profile | `project2/` | Fetches and displays a GitHub user profile from the GitHub API |
| 3 | Calculate Your Marks + Percentage | `project3/` | Grade calculator that takes subject marks and outputs the percentage |
| 4 | Math Question Game | `project4/` | Timed math quiz with generated questions and a score |
| 5 | Document | `project5/` | Additional HTML/CSS document practice |
| 6 | Color Palette Generator | `project6/` | Generates random color palettes you can copy as CSS |
| 7 | QR Code Generator | `project7/` | Turns a URL or text into a scannable QR code |
| 8 | Expense Tracker | `project8/` | Log, categorize, and total daily expenses |
| 9 | Password Generator App | `project9/` | Generates strong random passwords with configurable length/characters |
| 10 | myTunes Website | `project10/` | Music player UI / iTunes-style landing page |

### Shared files

- `images/` — preview thumbnails (`p1.png` … `p10.png`) and a `hero.png` banner used by the projects

## Getting started

```bash
git clone https://github.com/sajidpathan72/HTML-CSS-JS_Projects-.git
cd HTML-CSS-JS_Projects-
```

Then open a project's `index.html` in your browser:

```bash
start project6/index.html
```

## Tech

- HTML5
- CSS3 (Flexbox, Grid, animations)
- Vanilla JavaScript (DOM manipulation, events, `localStorage`, `fetch`)
